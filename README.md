# WGII_attendencecheck

## Streamlit App

This project includes a reusable Streamlit app for comparing attendee names with RSVP names.

### Install

```bash
pip install -r requirements.txt
```

### Run

```bash
streamlit run app.py
```

### Workflow

1. Upload Attendee List workbook in the first tab.
2. Upload LAM RSVP workbook in the second tab.
3. Open the download tab, generate the marked file, then download it.
